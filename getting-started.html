Getting Started with Konflux

Get your first secure CI/CD pipeline running in minutes. Follow these steps to set up Konflux and start producing tamper-proof software builds.

1

Prerequisites

Before you begin, ensure you have access to a Konflux instance and the required tools installed.

  • A Kubernetes cluster
  • kubectl CLI tool
  • A GitHub or GitLab account
  • Container registry access
2

Install Konflux

Deploy Konflux to your cluster using the provided Helm chart or operator.

  • Clone the konflux-ci repository
  • Configure your values.yaml
  • Deploy using helm install
  • Verify all pods are running
3

Connect Your Repository

Link your git repository to Konflux to start automated pipeline builds.

  • Log in to the Konflux console
  • Create a new application
  • Add your git repository URL
  • Configure build settings
4

Run Your First Build

Trigger your first Konflux pipeline and watch it build, sign, and verify your software.

  • Push a commit to trigger the pipeline
  • Monitor the build in the console
  • View generated SBOM and provenance
  • Release your verified artifacts
